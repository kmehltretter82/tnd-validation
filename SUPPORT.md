# Getting help

Open a [GitHub issue](https://github.com/kmehltretter82/tndlib/issues) for questions about
tasks or the Choir workflow, and for a check that fails for reasons outside your proof or
stays pending. Include the issue or pull request number and a link to the run.

The maintainer, [@kmehltretter82](https://github.com/kmehltretter82), reviews proofs and
answers these. This is one person's project, so a reply can take some days.

To report a suspected flaw in the verifier, do not open a public issue describing an
exploit. Use GitHub's private vulnerability reporting on this repository.
